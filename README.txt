Shop Zetu redesign - static mockup (Black November)

Deploy on Vercel: unzip, then either run `npx vercel` inside this folder, or push the folder to a GitHub repo and import it in Vercel as a static project (no build step, output directory = /).
Pages: index.html (home), collection.html, product.html, cart.html, checkout.html, login.html, account.html, wishlist.html, brands.html, vivo.html (brand shop), search.html, blog.html, article.html, about.html, careers.html, delivery-returns.html, refund-exchange-policy.html, 404.html, state-mega-menu.html, state-mobile-menu.html.
Black November values: the offer/delivery/end-date copy is in the HTML ([XX] placeholders); the countdown end date is ENDS_AT in site.js.
